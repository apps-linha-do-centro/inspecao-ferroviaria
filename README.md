# Inspeção Ferroviária · Apps Linha do Centro

## Aplicativos publicados

- **[Abrir Inspeção Ferroviária](https://apps-linha-do-centro.github.io/inspecao-ferroviaria/)** — registro de inspeções ferroviárias.
- **[Abrir Notas LC · Conferência em campo](https://apps-linha-do-centro.github.io/inspecao-ferroviaria/notas-lc-campo/)** — consulta e conferência de notas de manutenção em campo.

Arquivos compilados para hospedagem no GitHub Pages. O código de desenvolvimento é mantido separadamente em repositório privado.

## Atualizações e versões

Cada publicação deve enviar uma nova compilação completa para a branch main. O GitHub Pages publica esses commits automaticamente. O histórico permite recuperar versões anteriores; para republicar uma versão antiga, restaure seus arquivos em um novo commit.

Alterações feitas no Sites não são sincronizadas automaticamente. A automação anterior foi excluída.

## Dados das inspeções

Os registros são armazenados localmente no navegador. Exporte os registros existentes antes de trocar o endereço utilizado; eles não são transferidos automaticamente entre sites.
