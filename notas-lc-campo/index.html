Uso offline e atualização da base

Abra com internet e aguarde “Pronto para uso offline” antes de ir ao trecho. No iPhone ou iPad, você pode adicionar este app à Tela de Início pelo menu Compartilhar do Safari.

As conferências ficam neste dispositivo. Limpar os dados do navegador pode apagá-las. Exporte os relatórios para guardar uma cópia.

A base é atualizada pelo responsável pelo aplicativo, com uma nova extração da MRS. A versão disponível aparece nesta tela. Atualizações preservam o histórico local e os dados utilizados nas avaliações.
